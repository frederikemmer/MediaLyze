# Prototyping und Featurekonzepte

Dieser Bereich sammelt frühe Featureideen, Konzepte, Interaktionsentscheidungen und Prototypen, bevor und während ein Feature umgesetzt wird.

## Arbeitsweise

- Lege für jedes Feature einen eigenen Unterordner mit einem kurzen, kleingeschriebenen Namen an, zum Beispiel `notifications/`.
- Bewahre Konzept, Designentscheidungen, offene Fragen, Prototypen und relevante Referenzen gemeinsam in diesem Featureordner auf.
- Halte in jedem Konzept Status, Datum, Umfang, Verhalten, Gestaltung, Barrierefreiheit, Integrationsablauf und verbleibende Entscheidungen fest.
- Kennzeichne Vorschläge und Arbeitsstände so, dass bestätigte Entscheidungen erkennbar bleiben.
- Wenn ein Feature umgesetzt oder veröffentlicht wird, übertrage sein endgültiges Verhalten in die passende kanonische Produktdokumentation und verknüpfe sie hier.

Die Codebasis und die kanonischen Produktdokumente beschreiben weiterhin das Verhalten der jeweils umgesetzten Version. Prototyping-Dokumente zeigen den aktuellen Planungsstand.
